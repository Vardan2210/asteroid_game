# Asteroids

A small learning project built in a day while exploring **Pygame** and learning how game development works in Python. The project is a simple recreation of the classic *Asteroids* arcade game.

This is primarily a learning exercise rather than a polished or production-quality project. The implementation is intentionally simple, and the code may not reflect the structure or practices I would use in a larger project. The goal was to get hands-on experience with Pygame, understand its core concepts, and see how the different pieces of a game fit together.

More polished projects and larger applications can be found elsewhere in my repositories.
